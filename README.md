# UMSI Engaged Learning Office: Student Resource Portal

SI 338 Client Project (Fall 2026), Juan Alonso-Allende.

Live site: https://aallendez.github.io/client_project_f26/

## Pages
- `index.html`: Home
- `preparing-starting.html`: Phases 1 and 2
- `during-experience.html`: Phase 3
- `wrap-up.html`: Wrap-up, impact and next steps
- `404.html`: Custom "page not found" page (served by GitHub Pages)

## Structure
- `css/reset.css`: reset stylesheet
- `css/style.css`: mobile-first styles, with `min-width` layers for tablet (48rem) and desktop (64rem)
- `js/main.js`: footer year, objective progress tracker, 404 helper
- `images/`: site images (credits are in HTML comments next to each image)
